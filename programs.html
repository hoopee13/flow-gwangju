컬러로 말해요

퍼스널컬러 × 첫인상

퍼스널컬러 진단에 소셜 요소를 더한 프로그램입니다. 진단 결과를 혼자 받고 끝내지 않고, 참가자끼리 서로의 첫인상 컬러를 골라주며 대화가 시작됩니다.

정원8명
소요 시간120분
참가비39,000–49,000원
Run sheet
  1. 웰컴 컬러카드 선택 — 오늘의 기분을 색으로 고르기
  2. 전문 강사의 그룹형 미니 퍼스널컬러 진단
  3. 참가자끼리 서로의 첫인상 컬러 골라주기
  4. 같은 계열 참가자끼리 스타일링 이야기
  5. 개인 컬러 결과 카드 제공 · 사진 촬영

1대1 정밀 진단이 아니라 8명이 함께하는 그룹형 미니 진단입니다. 결과 카드는 당일 가져가실 수 있습니다.

FLOW MOVE

Rally & Rotate

초보 배드민턴

운동 경험이 거의 없는 사람을 위한 배드민턴 소셜링입니다. 잘 치는 사람들의 동호회가 아니라, 처음 라켓을 잡는 사람도 편한 모임으로 진행합니다.

정원12명
소요 시간90분
참가비22,000–28,000원
Run sheet
  1. 15분 기본 자세와 안전 교육
  2. 실력 대신 랜덤으로 2인 팀 구성
  3. 10분마다 파트너 교체
  4. 승패 대신 랠리 횟수 미션 진행
  5. 종료 후 음료와 3–4인 소그룹 대화

라켓과 셔틀콕은 준비되어 있습니다. 편한 운동복과 실내용 운동화만 챙겨 오세요.

FLOW SOUND

세 코드로 한 곡

기타 합주

악기를 배운 경험이 없는 참가자들이 기타 코드 세 개만으로 한 곡을 함께 연주하는 프로그램입니다. 혼자서는 어려운 일이 여럿이면 두 시간 만에 가능해집니다.

정원8명
소요 시간120분
참가비32,000–42,000원
Run sheet
  1. 기타 잡는 법과 기본 리듬 익히기
  2. 코드 세 개 연습
  3. 2–3명씩 작은 팀 구성
  4. 팀별 파트를 나눠 한 곡 합주
  5. 마지막 연주 영상 촬영 · 공유

기타는 대여해 드립니다. 악보를 몰라도 괜찮습니다.

FLOW TABLE

오늘의 취향 식탁

음식 × 질문카드

음식과 질문카드를 매개로 대화하는 소규모 프로그램입니다. 코스가 바뀔 때마다 자리를 옮겨 모든 참가자와 한 번씩 이야기하게 됩니다.

정원8명
소요 시간120분
참가비30,000–45,000원
Run sheet
  1. 신청 시 자신의 취향을 나타내는 물건이나 사진 하나 준비
  2. 4명씩 두 테이블로 시작
  3. 음식이 바뀔 때마다 자리 이동
  4. 질문카드는 가벼운 취향 주제부터
  5. 마지막에 서로 추천하고 싶은 광주 장소 공유

연애나 이상형 질문은 다루지 않습니다. 취향과 일상, 이 도시 이야기에 집중합니다.

FLOW MIX

한 곡의 밤

플레이리스트 교환회

각자 좋아하는 노래 한 곡을 가져와 함께 듣고 이야기하는 프로그램입니다. 누가 어떤 곡을 왜 좋아하는지 듣다 보면 대화가 자연스럽게 이어집니다.

정원10명
소요 시간90분
참가비15,000–25,000원
Run sheet
  1. 신청할 때 노래 링크 제출
  2. 현장에서 1인당 3분씩 노래와 사연 소개
  3. 비슷한 음악 취향끼리 팀 구성
  4. 팀별로 하나의 플레이리스트 완성
  5. 행사 후 전체 플레이리스트 공유

신청할 때 좋아하는 노래 한 곡의 링크를 남겨 주세요. 장르는 무엇이든 괜찮습니다.

FLOW LOCAL

빛 따라 걷는 밤

야간 산책 × 사진

동명동·국립아시아문화전당·양림동처럼 걷기 좋은 곳을 함께 걷는 야간 산책입니다. 나란히 걸으며 이야기하는 편이 마주 앉는 것보다 편할 때가 있습니다.

정원12명
소요 시간90분
참가비12,000–20,000원
Run sheet
  1. 출발 전 랜덤 2인 미션카드 배부
  2. 장소별 사진 미션 수행
  3. 20분마다 대화 파트너 교체
  4. 마지막 카페에서 사진 공유
  5. 참가자 투표로 ‘오늘의 한 장’ 선정

약 2km를 천천히 걷습니다. 편한 신발을 신어 주세요. 비가 오면 실내 코스로 대체합니다.

FLOW SCENT

나를 닮은 향

향수 · 룸스프레이 만들기

향을 만들면서 서로의 이미지를 향으로 표현해보는 프로그램입니다. 완성한 향에 이름을 붙이고 향 카드를 교환하며 마무리합니다.

정원8명
소요 시간120분
참가비39,000–55,000원
Run sheet
  1. 여러 향을 맡고 각자 취향 기록
  2. 참가자끼리 서로 어울리는 향 추천
  3. 전문 호스트와 개인 향 조합
  4. 완성한 향에 이름 붙이기
  5. 사진 촬영과 향 카드 교환

완성한 향은 그날 가져가실 수 있습니다. 향에 민감한 편이라면 미리 알려 주세요.

FLOW SIDE

본업 밖의 나

사이드 프로젝트 설계

직장인뿐 아니라 대학생·취업준비생도 참여할 수 있는 사이드 프로젝트 프로그램입니다. 거창한 창업이 아니라 30일 안에 끝낼 수 있는 작은 시도를 함께 설계합니다.

정원10명
소요 시간120분
참가비18,000–28,000원
Run sheet
  1. 내가 해보고 싶었던 일 적기
  2. 관심 분야별 3인 그룹 구성
  3. 30일 안에 할 수 있는 작은 프로젝트 설계
  4. 서로의 프로젝트에 아이디어 제공
  5. 한 달 뒤 온라인 체크인

결과물을 가져오지 않아도 됩니다. 해보고 싶었던 일 하나만 떠올려 오세요.
