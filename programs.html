컬러로 말해요

퍼스널컬러 × 첫인상

퍼스널컬러 진단에 소셜 요소를 더한 프로그램입니다. 진단 결과를 혼자 받고 끝내지 않고, 참가자끼리 서로의 첫인상 컬러를 골라주며 대화가 시작됩니다.

정원8명
소요 시간120분
참가비39,000–49,000원
운영 부담중간 · 강사 필요
추천FLOW 첫 참여 / 비주얼 콘텐츠
Run sheet
  1. 웰컴 컬러카드 선택 — 오늘의 기분을 색으로 고르기
  2. 전문 강사의 그룹형 미니 퍼스널컬러 진단
  3. 참가자끼리 서로의 첫인상 컬러 골라주기
  4. 같은 계열 참가자끼리 스타일링 이야기
  5. 개인 컬러 결과 카드 제공 · 사진 촬영

사진과 영상이 잘 나와 첫 고객을 모으는 대표 프로그램으로 좋습니다. 다만 1대1 정밀 진단이 아니라 그룹형 미니 진단임을 모집 페이지에 명확히 안내합니다.

FLOW MOVE

Rally & Rotate

초보 배드민턴

운동 경험이 거의 없는 사람을 위한 배드민턴 소셜링입니다. 잘 치는 사람들의 동호회가 아니라, 처음 라켓을 잡는 사람도 편한 모임으로 진행합니다.

정원12명
소요 시간90분
참가비22,000–28,000원
운영 부담낮음 · 라켓 대여 포함
추천반복 참여 / 정기 프로그램
Run sheet
  1. 15분 기본 자세와 안전 교육
  2. 실력 대신 랜덤으로 2인 팀 구성
  3. 10분마다 파트너 교체
  4. 승패 대신 랠리 횟수 미션 진행
  5. 종료 후 음료와 3–4인 소그룹 대화

한 번 온 사람이 다시 오기 가장 쉬운 형태입니다. 반응이 좋으면 격주 정기 MOVE CLUB으로 키울 수 있습니다.

FLOW SOUND

세 코드로 한 곡

기타 합주

악기를 배운 경험이 없는 참가자들이 기타 코드 세 개만으로 한 곡을 함께 연주하는 프로그램입니다. 혼자서는 어려운 일이 여럿이면 두 시간 만에 가능해집니다.

정원8명
소요 시간120분
참가비32,000–42,000원
운영 부담중간 · 기타 대여 필요
추천성취감 / 후기 영상
Run sheet
  1. 기타 잡는 법과 기본 리듬 익히기
  2. 코드 세 개 연습
  3. 2–3명씩 작은 팀 구성
  4. 팀별 파트를 나눠 한 곡 합주
  5. 마지막 연주 영상 촬영 · 공유

기타 대여가 가능한 호스트와 협업해야 운영이 편합니다. 반응이 좋으면 3주 완성 기타 클럽으로 확장할 수 있습니다.

FLOW TABLE

오늘의 취향 식탁

음식 × 질문카드

음식과 질문카드를 매개로 대화하는 소규모 프로그램입니다. 코스가 바뀔 때마다 자리를 옮겨 모든 참가자와 한 번씩 이야기하게 됩니다.

정원8명
소요 시간120분
참가비30,000–45,000원
운영 부담중간 · 공간 협업
추천깊은 대화 / 재참여 유도
Run sheet
  1. 신청 시 자신의 취향을 나타내는 물건이나 사진 하나 준비
  2. 4명씩 두 테이블로 시작
  3. 음식이 바뀔 때마다 자리 이동
  4. 질문카드는 가벼운 취향 주제부터
  5. 마지막에 서로 추천하고 싶은 광주 장소 공유

소개팅처럼 보이지 않도록 연애·이상형 질문은 제외하고 취향·일상·도시 이야기에 집중합니다.

FLOW MIX

한 곡의 밤

플레이리스트 교환회

각자 좋아하는 노래 한 곡을 가져와 함께 듣고 이야기하는 프로그램입니다. 장소와 스피커만 있으면 되어 운영 부담이 가장 작습니다.

정원10명
소요 시간90분
참가비15,000–25,000원
운영 부담낮음 · 운영진 진행 가능
추천저비용 테스트 / 감성 콘텐츠
Run sheet
  1. 신청할 때 노래 링크 제출
  2. 현장에서 1인당 3분씩 노래와 사연 소개
  3. 비슷한 음악 취향끼리 팀 구성
  4. 팀별로 하나의 플레이리스트 완성
  5. 행사 후 전체 플레이리스트 공유

비용이 거의 들지 않아 소셜링 구조 자체를 검증하기에 가장 좋은 프로그램입니다.

FLOW LOCAL

빛 따라 걷는 밤

야간 산책 × 사진

동명동·국립아시아문화전당·양림동처럼 걷기 좋은 지역을 활용한 야간 산책 프로그램입니다. 가격 진입장벽이 낮아 FLOW의 입문 코스로 좋습니다.

정원12명
소요 시간90분
참가비12,000–20,000원
운영 부담낮음 · 우천 대체 코스 필요
추천신규 참가자 유입
Run sheet
  1. 출발 전 랜덤 2인 미션카드 배부
  2. 장소별 사진 미션 수행
  3. 20분마다 대화 파트너 교체
  4. 마지막 카페에서 사진 공유
  5. 참가자 투표로 ‘오늘의 한 장’ 선정

우천 시 실내 대체 코스를 미리 준비하고, 모집 페이지에 안내해야 취소율이 낮아집니다.

FLOW SCENT

나를 닮은 향

향수 · 룸스프레이 만들기

향을 만들면서 서로의 이미지를 향으로 표현해보는 프로그램입니다. 완성한 향에 이름을 붙이고 향 카드를 교환하며 마무리합니다.

정원8명
소요 시간120분
참가비39,000–55,000원
운영 부담중간 · 강사·재료비
추천높은 만족도 / 선물성
Run sheet
  1. 여러 향을 맡고 각자 취향 기록
  2. 참가자끼리 서로 어울리는 향 추천
  3. 전문 호스트와 개인 향 조합
  4. 완성한 향에 이름 붙이기
  5. 사진 촬영과 향 카드 교환

특정 성별 전용처럼 보이지 않도록 비주얼을 중성적으로 구성하는 것이 중요합니다.

FLOW SIDE

본업 밖의 나

사이드 프로젝트 설계

직장인뿐 아니라 대학생·취업준비생도 참여할 수 있는 사이드 프로젝트 프로그램입니다. 거창한 창업이 아니라 30일 안에 끝낼 수 있는 작은 시도를 함께 설계합니다.

정원10명
소요 시간120분
참가비18,000–28,000원
운영 부담낮음 · 운영진 진행 가능
추천커리어 · 재참여 커뮤니티
Run sheet
  1. 내가 해보고 싶었던 일 적기
  2. 관심 분야별 3인 그룹 구성
  3. 30일 안에 할 수 있는 작은 프로젝트 설계
  4. 서로의 프로젝트에 아이디어 제공
  5. 한 달 뒤 온라인 체크인

운영진의 본업이 따로 있다는 브랜드 스토리를 가장 잘 보여주는 프로그램입니다. 생활 단계 차이가 큰 주제이므로 PEER FLOW(20–26 / 27–34)로 나눠 여는 것을 권합니다.

Roadmap

처음 두 달은 네 개만

여덟 개를 한꺼번에 준비하지 않습니다. 성격이 서로 다른 네 개를 먼저 열어 어떤 수요가 강한지 비교한 뒤, 나머지를 추가합니다.

순서프로그램검증 목적비용 부담
1FLOW TONE강한 비주얼로 브랜드 첫인상 형성중간
2FLOW MIX적은 비용으로 소셜링 구조 테스트낮음
3FLOW MOVE반복 참여 가능성 검증낮음
4FLOW LOCAL신규 참가자의 진입장벽 완화낮음

FLOW SOUND · TABLE · SCENT · SIDE는 첫 참가자 후기와 운영 경험이 쌓인 뒤 추가합니다. 참가비는 공간·강사·재료비에 따라 프로그램별로 확정되며, 위 금액은 기준 범위입니다.
